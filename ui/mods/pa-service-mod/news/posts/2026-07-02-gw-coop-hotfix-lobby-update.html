GW Co-op - Hotfix & Lobby Update

Greetings Commanders!

Thank you for the incredible response to the Galactic War Co-op launch. You jumped into the fight together in numbers we didn't expect, (and frankly struggled to handle!) and you sent us a mountain of feedback, logs, and bug reports along the way. This hotfix addresses some of the more urgent ones and brings some brand new QoL improvements to the multiplayer lobby experience plus a number of Co-op improvements.

A quick note on UI lag: we're aware that some players have been running into UI lag, and we're actively looking into it. The causes can vary from system to system, but some players have reported relief by turning off multithreading or running the game with hardware acceleration disabled. Hop into the official Discord for updates and per-system support — we're on it.

A better lobby

We've added three new lobby tools to make setting up a game less of a chore:

  • Auto-start — kick off the match automatically once everyone's ready.
  • Ping AFK — send a sound alert and taskbar notification to only the players who've wandered off, instead of blasting the whole lobby.
  • Make Host — hand host privileges over to another player without leaving the lobby.

We've also reworked the unready rules so the lobby stops resetting after every change. From now on:

  • Most actions that used to unready everyone — like adding or removing slots and teams — no longer do.
  • Moving or swapping players only unreadies the players involved.
  • Swapping the system won't unready anyone.
  • Changing game rules or eco modifiers still unreadies everyone, since those affect the whole match.

Finally, we've renamed the Quick Host drop-down button to Skirmish to make it clearer what it does.

Galactic War Co-op — fixes & polish

Fixes

  • Fixed a race condition that could corrupt inventory data, leaving players with empty inventories the first time they opened a campaign to Co-op.
  • All empty slots must now be filled or removed before a battle can be launched from the galactic map. This closes a rare window where a player could join after the battle had already started loading.

Quality of life

  • Continue War now reopens as many slots as were open when you started the battle.
  • Co-op players can now see the Continue War button — clicking it shows "Awaiting host" so everyone understands the flow instead of wondering why nothing's happening.
  • Co-op players are no longer treated as subcommanders for defeat detection. Unless Sudden Death is on, the host dying will no longer wipe out the whole team.
  • The Dismiss Tech and tech-choice rows are back for Co-op players on shared tech — on the Co-op side they now read "Host Choosing Tech" so it's obvious why the buttons aren't available.
  • Removed the misleading friends-visibility option, since the friend list is currently non-functional.

For the modders

  • Mods in Co-op — we've added the infrastructure to support mods in Co-op. Galactic War mods now have a mechanism to synchronize any game-state changes to every connected client.
  • The mod-mismatch warning screen now reads the new galacticWarMod: true field from your modinfo.json. Players can no longer bypass the mismatch screen when a mismatch is detected — everyone plays on the same page.
  • The server beacon now reports active Galactic War mods, the same way it reports server mods.

Thank you

Every fix in this list started as a bug report, a log file, or a "hey, this feels off" in the Discord. Keep it coming — Co-op and PA as a whole are only going to get better from here. Stay tuned for some exciting intel soon…
