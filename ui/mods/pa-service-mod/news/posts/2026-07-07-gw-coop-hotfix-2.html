Galactic War Co-op Hotfix 2

We've been hard at work addressing more of your feedback on Co-op Galactic War, along with a couple of long-standing bug fixes. Here's what's new:

Co-op Galactic War:

  • Persistent titles & passwords: Saves now remember the most recent lobby title and password. No more retyping the same details every time you boot up the same campaign!
  • Fixed an issue where opening a campaign to Co-op for the first time with separate Tech enabled could wipe the host's inventory.
  • Fixed a minor display bug where some Galactic War server beacons showed raw !LOC: text as part of the system name.

Bug Fixes

  • Resolved a common effect-related crash frequently seen when reconnecting to a modded game.
  • Fixed a common issue where players would get stuck on "Loading Mods" when launching the game.

Quality of Life

  • Persistent wreckage: Once spotted, wreckage now stays visible in the fog of war instead of vanishing when you lose line of sight.

For Modders

  • Multi-bone transporters: Transporters can now define an array of attachment bones. If a transport carries multiple units, each unit can be attached to its own unique bone instead of all hooking onto the same one.
  • You can now specify a default title for Galactic War campaigns instead of "GW Co-op Campaign": When touching the gw_play scene, mods can make use of setDefaultGwCoopLobbyTitle(string).

Known Issues

  • The Friends system is offline while we build a replacement — stay tuned!
  • The "comm bug": commanders occasionally spawn without vision of any units, including your own commander.
  • PA Chat is near capacity and can be unreliable right now.
  • The build bar can appear in the wrong place, or not at all, when selecting units — a fix is planned for the next release.
  • The UI can occasionally lag or hang.
  • The game can appear to run while the simulation has actually stopped. If this happens, set Settings → Server → Local Server Multi-Threading to OFF.

Co-Op GW Known Issues

  • The client and server galactic map can briefly fall out of sync — this is purely visual.
  • Clients sometimes fail to automatically rejoin a Galactic War session when continuing the war. Work is ongoing.

OS-Specific Issues

  • Linux: occasional 'cilantro' error code on the native port.
  • Windows: Smart App Control can block the server executable — disable it, or add your PA install folder to Windows Defender's exclusions, to work around it.

Keep on reporting bugs and suggesting improvements! We truly appreciate your feedback, as most of our fixes start off as a report from you in the Discord.
